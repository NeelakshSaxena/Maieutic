# Maieutic Training Dashboard

This is a lightweight local dashboard to monitor SFT training. It uses a single read-only Flask endpoint and reads from the `metrics.jsonl` log file generated by the `MonitorCallback` during training.

## Usage

Start the dashboard:
```bash
python training/monitor/dashboard.py
```

It will run on `http://0.0.0.0:8000`. You can access it through the RunPod exposed HTTP port.

## Testing
To verify the dashboard before training, run:
```bash
python training/monitor/test_mock.py
```
This will append mock metrics (marked with `is_mock: true`).
**Ensure you delete `training/outputs/monitor/metrics.jsonl` before starting real training!**
